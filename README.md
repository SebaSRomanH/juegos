## Salto Cósmico

Juego de Rafa: salta de planeta en planeta por la Vía Láctea, esquiva agujeros negros, usa supernovas para volar y saluda a los alienígenas.

- Código: [`salto-cosmico/index.html`](salto-cosmico/index.html)
- Para jugar, descarga el archivo y ábrelo en el navegador (computador o celular).
- Controles: Espacio o ↑ para saltar (mantén para la propulsión), ↓ para bajar, ← → para frenar y acelerar, P para pausa. En el celular aparecen botones en pantalla.
